# Allele Extractor

A Python tool that uses computer vision and OCR to automatically extract alleles and loci from DNA profile PDF reports and compile them into an Excel table.

## Features

- Automatically detects and extracts allele values for each locus from PDF DNA profile reports
- Batch processes an entire folder of PDF files
- Outputs results as Excel (`.xlsx`) files, one per input PDF
- Preserves original file names in the output
- Keeps a processing log (`processed_files.log`) and skips files already processed (successfully or with an error) on subsequent runs, so a batch can be safely re-run or resumed

## Limitations

- Works only with PDF reports generated by forensic DNA analysis software (a specific, structured report format)
- Does **not** work with scanned PDFs or photographs of DNA profiles (no general-purpose OCR/layout detection)
- Currently does **not** extract Amelogenin or Y-indel markers (planned for a future release)
- File names cannot be in Cyrillic
- **Windows only** in the current version — file paths (including the path to the bundled Tesseract executable) are hardcoded with Windows-style backslashes

## Requirements & Setup

This repository ships as a self-contained Windows package. It bundles everything needed to run it:

- `python-3.14.6/` — a portable Python 3.14.6 build with all required packages already installed
- `Tesseract-OCR/` — a portable Tesseract OCR 5.x build with the English (`eng`) trained data

No separate installation of Python, pip packages, or Tesseract is required. Clone or download the repository and run it directly with the bundled interpreter (see Usage below).

If you'd rather use your own Python installation instead of the bundled one, install the packages listed in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) (versions currently bundled are listed there) and install Tesseract OCR separately for your OS. In that case you'll also need to update the hardcoded path in `allele_extractor_ver1.py`:

```python
pytesseract.pytesseract.tesseract_cmd = r".\Tesseract-OCR\tesseract.exe"
```

## Installation

```bash
git clone https://github.com/yourusername/allele-extractor.git
cd allele-extractor
```

That's it — the bundled `python-3.14.6/` and `Tesseract-OCR/` folders are ready to use as-is.

> **Note on repository size:** the bundled Python and Tesseract folders include several large compiled binaries (DLLs, the OCR engine, trained language data, and compiled Python packages such as OpenCV, NumPy and pandas). These are tracked with [Git LFS](https://git-lfs.com/) (see `.gitattributes`) instead of being stored directly in git history. Make sure Git LFS is installed (`git lfs install`) before cloning or pulling this repository, otherwise the large files will show up as small pointer files instead of their real content.

## Usage

Run the script with the bundled Python interpreter, pointing it to a folder containing your input PDF files:

```bash
.\python-3.14.6\python.exe .\allele_extractor_ver1.py --input "path\to\folder\with\pdf\files"
```

### Output

Results are automatically saved to a new folder named `results`, created in the working directory. Each output Excel file keeps the same name as its corresponding input PDF (with `.xlsx` appended).

Processing progress is recorded in `processed_files.log` (timestamp, success/error status, and processing time per file). Files already listed there are skipped if you run the script again on the same input folder.

⚠️ **Important:** This tool processes DNA profile data, which may constitute sensitive personal and forensic information. Users are responsible for:

- Ensuring compliance with applicable data protection laws and regulations (e.g. GDPR, local forensic data handling policies) when processing DNA profiles
- Handling all input PDFs and output Excel files securely, and restricting access to authorized personnel only
- Not committing real DNA profile data, sample outputs, or any personally identifiable information to this repository or any public location

This project does not transmit data externally — all processing happens locally on your machine.

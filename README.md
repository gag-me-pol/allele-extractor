# Allele Extractor

A Python tool that uses computer vision and OCR to automatically extract alleles and loci from DNA profile PDF reports and compile them into an Excel table.

## Features

- Automatically detects and extracts allele values for each locus from PDF DNA profile reports
- Batch processes an entire folder of PDF files
- Outputs results as Excel (`.xlsx`) files, one per input PDF
- Preserves original file names in the output

## Limitations

- Works only with PDF reports generated by forensic DNA analysis software (a specific, structured report format)
- Does **not** work with scanned PDFs or photographs of DNA profiles (no general-purpose OCR/layout detection)
- Currently does **not** extract Amelogenin or Y-indel markers (planned for a future release)
- File names cannot be in Cyrillic.

## Requirements

- Python 3.x
- A virtual environment with the packages listed in `requirements.txt`
- [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) installed manually on your system (not installable via pip alone)

### Installing Tesseract OCR

- **Linux (Debian/Ubuntu):**
  ```bash
  sudo apt install tesseract-ocr
  ```
- **macOS:**
  ```bash
  brew install tesseract
  ```
- **Windows:**
  Download and run the installer from the [official Tesseract repository](https://github.com/UB-Mannheim/tesseract/wiki), and make sure it's added to your system PATH.

## Installation

```bash
git clone https://github.com/yourusername/allele-extractor.git
cd allele-extractor

python3 -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

pip install -r requirements.txt
```

Then install Tesseract OCR as described above.

## Usage

Run the script from the terminal, pointing it to a folder containing your input PDF files:

```bash
python3 ./allele_extractor_ver1.py --input "path/to/folder/with/pdf/files"
```

*(Linux example — adjust path syntax for Windows if needed.)*

### Output

Results are automatically saved to a new folder named `df_dir`, created in the working directory. Each output Excel file keeps the same name as its corresponding input PDF.
